## Commands Reference

### Generate single god portrait:
```typescript
Tool: generate_god_portrait
{
  "godName": "Thor",
  "domain": "thunder and strength",
  "attributes": ["red beard", "Mjolnir", "lightning"],
  "mood": "fierce and heroic",
  "outputPath": "public/images/gods/thor"
}
```

### Generate single story illustration:
```typescript
Tool: generate_story_illustration
{
  "storyName": "Theft of Mjolnir",
  "scene": "Thor dressed as bride, Loki as bridesmaid",
  "mood": "comedic absurdity",
  "outputPath": "public/images/stories/mjolnir-disguise"
}
```

### Batch generate category:
```typescript
Tool: batch_generate_images
{
  "category": "gods",
  "limit": 11
}
```
